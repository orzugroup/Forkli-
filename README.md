# Lingua Studio — демо-система языковой школы

Локальный интерактивный макет административной системы для одной языковой школы. Все изменения хранятся только в состоянии страницы и исчезают после обновления. Данные и портреты демонстрационные; сервер, авторизация, платежи и внешние интеграции не подключены.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173/`).

## Что показать на презентации

1. **Обзор** — статус школы, занятия недели и приоритетные задачи администратора.
2. **Ученики** — поиск, фильтры по языку/уровню/группе/оплате, сортировка, выбор нескольких записей и CSV-экспорт.
   В профиле есть контактные данные ученика и опекуна, уровень CEFR и курс, преподаватель, посещаемость, история оплат и внутренние заметки. Профиль можно редактировать, добавить счёт за следующий период, отметить оплату и подготовить текст напоминания.
3. **Группы** — состав, язык, уровень CEFR, преподаватель, расписание и набор.
4. **Преподаватели** — команда и учебная нагрузка с демонстрационными фотографиями.
5. **Расписание** — неделя, фильтр по дням и добавление урока.
6. **Оплата** — список счетов и изменение статуса оплаты в макете.
7. **Отчёты** — посещаемость и распределение по языкам.
8. **Настройки** — название школы, язык интерфейса, часовой пояс и форматы.

Портреты из `public/avatars/` и карточки учеников созданы специально для презентационного макета и не изображают реальных людей. Оплаты, счета, заметки, контакты и учебные события демонстрационные. Счёт можно создать и оплату отметить внутри макета; настоящего регулярного списания, отправки напоминаний или хранения после обновления страницы нет.

## До реального запуска

Нужны сервер и база данных, вход сотрудников и роли, журналирование действий, резервные копии, правила хранения и удаления данных, а также согласованные документы для школы. Для несовершеннолетних отдельно спроектируйте процесс уведомления родителей/опекунов и обработки соответствующих согласий с учётом страны работы школы.
