# Forkli — демо админ-системы языковой школы

Профессиональный интерактивный макет для демонстрации управления одной языковой школой: ученики, группы, преподаватели, расписание, оплата, отчёты и настройки.

## Публичное демо

[Открыть демо Forkli](https://forkli-demo.vercel.app/)

Все имена, портреты, контакты и финансовые показатели демонстрационные. Изменения работают в браузерной сессии и сбрасываются после перезагрузки. Демо не принимает реальные платежи, не отправляет письма и не хранит пользовательские данные.

## Возможности интерфейса

- **Обзор:** ключевые показатели, ближайшие занятия, задачи администратора, языковые направления и заполняемость групп.
- **Ученики:** поиск и фильтры, карточки профиля, курс и CEFR, посещаемость, платежный статус и CSV-экспорт.
- **Группы:** создание учебных групп, распределение учеников, преподавателей и расписания.
- **Преподаватели:** список команды и учебная нагрузка.
- **Расписание:** недельный календарь и добавление занятий.
- **Оплата:** демонстрационный реестр счетов, статусов и действий по платежам.
- **Отчёты:** аналитика по ученикам, посещаемости, группам и платежам.
- **Настройки:** данные школы, локаль, учебные стандарты, тарифы, уведомления, команда и параметры защиты.
- **Профиль администратора и уведомления:** редактирование демонстрационных данных профиля и работа с центром уведомлений.

## Запуск локально

Требуется Node.js и npm.

~~~bash
npm install
npm run dev
~~~

Для локальной production-сборки:

~~~bash
npm run build
npm run preview
~~~

## Развёртывание на Vercel

Репозиторий подключается в Vercel: **orzugroup/Forkli-**.

Конфигурация в vercel.json указывает команду npm run build и каталог готового сайта dist. Корневая директория проекта — корень репозитория. После подключения Git каждый push в main создаёт production-деплой. Для клиентской презентации используйте стабильный адрес проекта: https://forkli-demo.vercel.app/.

## Перед реальным использованием школой

Это презентационный фронтенд без сервера и базы данных. Для работы с реальными учениками потребуются авторизация и роли, серверное хранение данных, резервные копии, аудит изменений, безопасная обработка платежей и документов, политика хранения и удаления персональных данных. Перед запуском школа должна отдельно определить применимые требования к обработке данных в своей стране, особенно для несовершеннолетних.
